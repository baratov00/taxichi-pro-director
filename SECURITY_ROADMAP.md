# Taxichi Pro Director: безопасность и доступы

## Что изменено

- Пароль админа задаётся только в директорском кабинете.
- Кнопка `Открыть кабинет` создаёт временный доступ на 10 минут.
- Админка открывается для директора в режиме просмотра: данные видно, изменения отключены.

## Что важно

Текущая версия сайтов ещё работает напрямую с Supabase через publishable key. Поэтому строгие RLS-политики нужно включать только после перехода важных операций на серверные функции.

Порядок включения:

1. Развернуть Edge Functions из админского репозитория.
2. Выполнить `supabase-security-hardening.sql` из админского репозитория.
3. Перевести оплату/списание/удаление/аудит на сервер.
4. Включить RLS.
5. Перевести открытые пароли на `password_hash`.

Так мы не ломаем текущий APK и постепенно переводим проект на нормальную серверную защиту.
